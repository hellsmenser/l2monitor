# Aden+ 1.0.0

Первый публичный релиз Windows-приложения Aden+.

## Главное

- одна пользовательская точка входа: `Aden+.exe`;
- фоновый компонент запускается и завершается вместе с приложением;
- опциональный автозапуск вместе с Windows;
- облачная работа через [@AdenPulse_bot](https://t.me/AdenPulse_bot);
- автономная отправка уведомлений через собственного Telegram-бота;
- self-contained сборка для Windows x64 — отдельно устанавливать .NET не нужно;
- приложение не запрашивает логины и пароли Lineage II; состав локальных и передаваемых технических данных явно описан в README;
- адрес облачного сервиса встроен в конфигурацию официальной сборки и не показывается в пользовательском интерфейсе;
- опубликован исходный код всех компонентов, работающих на компьютере пользователя.
- проверка новой версии через публичный endpoint backend работает в автономном и облачном режимах;
  устаревшая версия показывает ежедневное Windows-уведомление и постоянный баннер в окне.
- политика конфиденциальности, удаление приложения и
  [Code signing policy](https://github.com/hellsmenser/l2monitor/blob/main/CODE_SIGNING.md)
  опубликованы вместе с исходным кодом и релизным архивом.

## Установка

1. Скачайте ZIP и файл `.sha256`.
2. Проверьте SHA-256 архива.
3. Полностью распакуйте архив.
4. Запустите `Aden+.exe`.

Подробная настройка описана в `README.md` внутри архива и на главной странице репозитория.

Пользователям из России в автономном режиме необходимо самостоятельно настроить доступ компьютера к серверам Telegram, например через VPN-туннель. Это находится за пределами Aden+. При использовании сервиса Aden+ приложение подключается напрямую к серверам Aden+, и прямой доступ компьютера пользователя к Telegram для доставки уведомлений не требуется.

## Проверка файла

```powershell
Get-FileHash .\AdenPlus-v1.0.0-win-x64.zip -Algorithm SHA256
```

Значение должно совпасть с содержимым `AdenPlus-v1.0.0-win-x64.sha256`.
