# Политика конфиденциальности Aden+

## Кратко

Aden+ не запрашивает и не хранит логин, пароль, коды двухфакторной
аутентификации или иные данные аккаунта Lineage II. Приложение не читает память
или файлы игрового клиента, не записывает ввод с клавиатуры и не перехватывает
содержимое сетевого трафика игры.

## Данные на компьютере пользователя

Aden+ локально хранит:

- настройки мониторинга и тексты уведомлений;
- фильтры заголовков окон;
- идентификатор привязанного Telegram-чата;
- ключ сервиса Aden+ или токен собственного Telegram-бота;
- текущее диагностическое состояние и ограниченные по размеру журналы работы.

Секреты хранятся в зашифрованном виде с помощью Windows DPAPI и привязаны к
текущему пользователю Windows. Пути к файлам перечислены в README.

## Автономный режим

В автономном режиме приложение обращается напрямую к Telegram Bot API. Telegram
получает идентификатор выбранного чата, токен созданного пользователем бота и
готовый текст уведомления. Сервис Aden+ в этом режиме не участвует.

## Режим сервиса Aden+

Облачный режим включается пользователем явно. Приложение подключается к адресу
сервиса Aden+, заданному в настройках, и передаёт:

- ключ авторизации Aden+ в заголовке соединения;
- имя устройства, используемое как его метка;
- версию приложения;
- служебные сигналы доступности, подключения и завершения работы.

Логины, пароли и другие данные игрового аккаунта не передаются. Доставку
Telegram-уведомлений выполняет сервис Aden+, поэтому компьютеру пользователя не
нужен прямой доступ к Telegram в этом режиме.

## Управление передачей данных

Доставка уведомлений по умолчанию выключена. Пользователь может выбрать
автономный или облачный режим либо полностью отключить доставку в настройках.
Удаление локальных данных выполняется вручную по путям из README или сценарием
удаления с параметром `-RemoveUserData`.

## Проверяемость

Исходный код клиента и сценарии его сборки открыты. Пользователь может проверить
сетевые запросы, локальное хранение и источники данных самостоятельно, с помощью
выбранного инструмента анализа или привлечённого специалиста.
