# Участие в разработке Aden+

## Перед началом

- не добавляйте ключи, токены, пользовательские журналы и другие секреты;
- сохраняйте границу проекта: клиент использует только косвенные источники ОС и
  не вмешивается в процесс или сетевой трафик игры;
- для исправления дефекта сначала добавьте воспроизводящий тест;
- пользовательские тексты и документация должны быть на русском языке.

## Локальная проверка

Требуются Windows 10/11 x64 и .NET 8 SDK.

```powershell
dotnet test .\L2Monitor.slnx -c Release
dotnet format .\L2Monitor.slnx --verify-no-changes --no-restore
powershell -NoProfile -ExecutionPolicy Bypass -File .\installer\Verify-L2MonitorInstaller.ps1
git diff --check
```

Pull request должен кратко описывать пользовательский эффект, риски и выполненные
проверки. Изменения сборочных сценариев требуют такой же проверки, как изменения
исполняемого кода.
