# Безопасность

## Сообщение об уязвимости

Не публикуйте рабочие ключи, токены, `secrets.dat`, журналы с личными данными или
описание ещё не исправленной критической уязвимости в открытом issue.

После публикации репозитория используйте приватный GitHub Security Advisory:
`Security` → `Advisories` → `Report a vulnerability`. Если приватный канал
временно недоступен, создайте публичный issue без эксплуатационных деталей и
попросите сопровождающего связаться с вами приватно.

В сообщении укажите версию Aden+, версию Windows, ожидаемое и фактическое
поведение, минимальные шаги воспроизведения и оценку возможного воздействия.

## Область ответственности

Принимаются сообщения об уязвимостях Windows-клиента Aden+, локального API,
хранения секретов, сборочных сценариев и механизма обновления. Не включайте в
проверки атаки на Telegram, Lineage II или сторонние сервисы без разрешения их
владельцев.
